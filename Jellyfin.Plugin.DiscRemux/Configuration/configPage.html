Disc Remux

Turns DVD folder rips (VIDEO_TS) and single VTS_xx_x.VOB files imported by Radarr/Sonarr into one MKV. Run it from Dashboard → Scheduled Tasks → Disc Remux.

Where to look

Download folders that still hold the complete disc. Used when Radarr/Sonarr imported only one VOB. Nothing in these folders is changed.
Recommended: the download client may delete the full disc later.

Audio

Plays on every TV/phone without transcoding. The original tracks are kept.

Subtitles

Empty = every subtitle language that has an installed tesseract model (recommended). Or limit it with ISO 639-1 codes, e.g. bg,en. Other languages stay as bitmap tracks in the MKV.
Its SRT is named .default.srt so clients turn it on. Empty = none.
Stops clients from picking the bitmap track instead of the SRT.

Safety

Empty = a hidden .disc-remux-original folder next to the movie. Nothing is ever deleted.
